      WHERE THE SPACE GOES

      Inside data storage

      Inspect top-level folders in the writable data area.

      Run a folder inspection to see what is using this space.

      Folder sizes count allocated space. Shared files, compression and filesystem metadata can make totals differ from the capacity meter. Inspecting does not remove files.

      Why can the SD card have space while data storage is full?

      The SD card is divided into separate partitions. This manager shows the filesystem space available to each one. Unpartitioned capacity and unused space inside another partition are not automatically available to presets or community installs.
